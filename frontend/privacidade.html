Política de Privacidade

Última atualização: 13 de Junho de 2026

1. Coleta de Informações

Coletamos apenas as informações estritamente necessárias para a prestação do serviço de agendamentos. Para os **profissionais**, coletamos: Nome Completo, Nome do Estabelecimento, E-mail, WhatsApp, CPF, Chave Pix, informações de login e senhas criptografadas. Para os **clientes finais**, coletamos: Nome e WhatsApp (para notificações).

2. Uso das Informações

Os dados coletados são usados exclusivamente para:

  • Gerenciar sua conta de administrador e as agendas vinculadas.
  • Gerar checkouts Pix para reservas de horários.
  • Enviar lembretes automáticos de agendamento via WhatsApp aos clientes.
  • Processar o faturamento da mensalidade do SaaS.

3. Compartilhamento de Dados

Não vendemos nem compartilhamos dados com anunciantes ou terceiros sem relação direta com os serviços. Os dados necessários para processamento financeiro são enviados de forma segura para o **Mercado Pago** (em integrações automáticas do profissional).

4. Segurança e Criptografia

Suas credenciais de acesso e senhas são criptografadas utilizando algoritmos de hash seguros (`bcrypt`). A plataforma é executada sob conexões seguras e criptografadas por protocolo HTTPS (SSL).

5. Direitos do Usuário (LGPD)

De acordo com a Lei Geral de Proteção de Dados (LGPD) brasileira, você tem o direito de solicitar o acesso, a retificação, a portabilidade ou a exclusão definitiva dos seus dados da nossa base de dados a qualquer momento, por meio do suporte administrativo oficial do sistema.
